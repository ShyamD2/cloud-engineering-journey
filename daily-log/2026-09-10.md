---

## The problem I ran into & how I solved it
* **What I was trying to do:** Running pytest step in the GitHub Actions runner
* **The error:** `Workflow failed with `ModuleNotFoundError: No module named 'src'`.`
* **What actually caused it:** The GitHub runner's `PYTHONPATH` didn't include the repository root directory.
* **How I fixed it:** Added `env: PYTHONPATH: .` to the test step in `.github/workflows/ci.yml`.
* **Takeaway / lesson learned:** Make sure CI runner environment paths match your local development environment.
