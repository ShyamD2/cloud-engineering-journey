---

## The problem I ran into & how I solved it
* **What I was trying to do:** Cleaning up a rebase that went sideways
* **The error:** `Got stuck in a detached HEAD state with conflict markers all over my working directory.`
* **What actually caused it:** I tried to rebase while having unstaged changes sitting around.
* **How I fixed it:** Ran `git rebase --abort` to return safely to where I started, ran `git stash` to tuck away my uncommitted edits, and ran the rebase again.
* **Takeaway / lesson learned:** Never panic when git rebases conflict. `git rebase --abort` is your escape hatch, and `git reflog` keeps a log of every HEAD change.

---

## Key takeaways from today
- Never rebase commits that have already been pushed to a shared remote branch.
- Squashing 'fix typo' and 'wip' commits before merging makes git history 10x easier to read during incident reviews.
