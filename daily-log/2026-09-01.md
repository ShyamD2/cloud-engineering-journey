---

## The problem I ran into & how I solved it
* **What I was trying to do:** Running terraform init
* **The error:** ``Error: Checksum verification failed for provider ...``
* **What actually caused it:** My `.terraform.lock.hcl` had hashes cached from a different platform.
* **How I fixed it:** Ran `terraform init -upgrade` to refresh the lock file for my current system.
* **Takeaway / lesson learned:** Commit `.terraform.lock.hcl` to git so everyone on the team uses identical provider versions.

---

## Key takeaways from today
- Terraform is declarative: you describe what you want, and Terraform figures out what to create, update, or destroy.
- Never manually edit resources in the AWS console if they are managed by Terraform.
