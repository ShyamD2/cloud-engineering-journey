## The problem I ran into & how I solved it
* **What I was trying to do:** Writing new short codes during concurrency testing
* **The error:** `Duplicate short codes were silently overwriting existing URL mappings.`
* **What actually caused it:** Default `put_item` overwrites items with the same partition key.
* **How I fixed it:** Added `ConditionExpression='attribute_not_exists(short_code)'` so DynamoDB throws `ConditionalCheckFailedException` if a key exists, triggering my retry loop.
* **Takeaway / lesson learned:** Always use Conditional Writes in DynamoDB when inserting records that shouldn't overwrite existing data.
