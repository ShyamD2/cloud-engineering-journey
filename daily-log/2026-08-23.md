# 2026-08-23 — Day 23: S3 Lifecycle Rules & Cost Optimization

Set up automated storage tiering in S3 today. Cloud storage is cheap, but if you leave terabytes of uncompressed logs in S3 Standard for years, the bill adds up quietly.

---

## What I worked on today
- Created an S3 Lifecycle Configuration targeting `logs/*` prefixes.
- Configured rules: transition to Standard-IA after 30 days, Glacier Flexible after 90 days, and expire after 365 days.
- Configured automatic cleanup of noncurrent object versions to prevent hidden versioning costs.

---

## Commands I ran
```bash
aws s3api put-bucket-lifecycle-configuration --bucket secure-data-vault-2026 --lifecycle-configuration file://lifecycle.json
aws s3api get-bucket-lifecycle-configuration --bucket secure-data-vault-2026
```

---

## The problem I ran into & how I solved it
* **What I was trying to do:** Applying transition rules to small log files (<128KB)
* **The error:** `Noticed files under 128KB were not transitioning to Standard-IA as expected.`
* **What actually caused it:** S3 Standard-IA has a minimum billable size of 128KB. AWS automatically skips transitioning smaller files to save you from paying for 128KB anyway.
* **How I fixed it:** Batched log files into larger archives before uploading, or left small files in S3 Standard.
* **Takeaway / lesson learned:** Always be mindful of minimum storage sizes and minimum storage durations (30 days for IA, 90 days for Glacier) before creating lifecycle rules.

---

## Key takeaways from today
- S3 Intelligent-Tiering has no retrieval fees and is ideal when data access patterns are unknown.
- Glacier Deep Archive is by far the cheapest cloud storage option ($0.00099/GB/month) for compliance backups.
