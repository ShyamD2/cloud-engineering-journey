# 2026-08-01 — Day 1: Linux Permissions, Ownership & Group Collaboration

Day 1 of the journey. Decided to start right from the Linux fundamentals. Even though I've used Ubuntu for a while, I realized I never really understood the SGID bit or how umask actually calculates default permissions under the hood.

---

## What I worked on today
- Created dedicated system groups (`devops` and `developers`) to test team-based directory access.
- Set up a shared directory at `/opt/projects/infra` with the SGID bit enabled (`chmod 2775`). That way, whenever anyone creates a file inside, it automatically inherits the `devops` group instead of the user's primary group.
- Tested how `umask 0027` changes default file permissions to `640` (rw-r-----) for files and `750` for directories.

---

## Commands I ran
```bash
# Create the group and add myself to it
sudo groupadd -g 2001 devops
sudo usermod -aG devops $USER

# Set up shared folder with SGID
sudo mkdir -p /opt/projects/infra
sudo chown -R root:devops /opt/projects/infra
sudo chmod -R 2775 /opt/projects/infra

# Verify the 's' bit is set in the group permissions
ls -ld /opt/projects/infra
```

---

## The problem I ran into & how I solved it
* **What I was trying to do:** Running a custom bootstrap shell script inside the shared directory
* **The error:** `Got `bash: ./deploy.sh: Permission denied` even after running `chmod +x deploy.sh`.`
* **What actually caused it:** The `/opt` partition on this VM was mounted with the `noexec` flag in `/etc/fstab`, which completely blocks executing binaries/scripts directly from that mount.
* **How I fixed it:** Removed `noexec` from `/etc/fstab` for `/opt`, remounted it with `sudo mount -o remount /opt`, and verified the script executed.
* **Takeaway / lesson learned:** Permissions aren't just file mode bits (`chmod`); filesystem mount options (`noexec`, `nosuid`) can override them completely.

---

## Key takeaways from today
- SGID on a directory (`chmod 2775` or `chmod g+s`) is the cleanest way to handle shared team folders in Linux.
- Umask subtracts permission bits from base permissions (666 for files, 777 for directories).
