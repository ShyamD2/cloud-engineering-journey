# 2026-09-06 — Day 37: AWS Cloud Cost Audit & Idle Resource Cleanup

Cost optimization day! Logged into AWS Cost Explorer to review usage. Noticed a tiny $0.0064 charge under EC2-Other and decided to do a complete sweep of all AWS regions to make sure zero idle resources are burning money.

---

## What I worked on today
- Checked AWS Cost Explorer across the last 30 days.
- Wrote an automated Boto3 Python script to scan all 18 enabled AWS regions for running EC2 instances, unattached EBS volumes, orphan Elastic IPs, NAT Gateways, and Load Balancers.
- Deleted an idle test Load Balancer and unattached volume left over from earlier labs.
- Brought ongoing daily AWS spend back to exactly $0.0000.

---

## Commands I ran
```bash
# Query Cost Explorer for recent charges
aws ce get-cost-and-usage --time-period Start=2026-09-01,End=2026-09-06 --granularity DAILY --metrics UnblendedCost --group-by Type=DIMENSION,Key=SERVICE

# Check for unattached EBS volumes
aws ec2 describe-volumes --filters Name=status,Values=available

# Check for unassociated Elastic IPs
aws ec2 describe-addresses --filters Name=association-id,Values=''
```

---

## The problem I ran into & how I solved it
* **What I was trying to do:** Finding the source of the tiny daily fee
* **The error:** `Cost Explorer showed tiny recurring fees under `EC2 - Other` and `Amazon Elastic Load Balancing`.`
* **What actually caused it:** A test load balancer and an unattached EBS volume were provisioned during previous experiments and forgotten.
* **How I fixed it:** Deleted the load balancer and released the unattached EBS volume and IP address immediately.
* **Takeaway / lesson learned:** Unattached Elastic IPs and orphaned EBS volumes cost money every hour even if all EC2 instances are stopped!

---

## Key takeaways from today
- AWS charges $0.005/hour for all public IPv4 addresses; don't leave unattached EIPs sitting around.
- Setting up AWS Budget alerts with SNS notifications is the best defense against surprise cloud bills.
