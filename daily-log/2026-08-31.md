## The problem I ran into & how I solved it
* **What I was trying to do:** Testing link redirects in the browser
* **The error:** `First click redirected fine, but repeated clicks didn't increment the analytics counter.`
* **What actually caused it:** I initially returned `HTTP 301 Moved Permanently`. Browsers cache 301 redirects aggressively, so repeated clicks never hit the API Gateway at all!
* **How I fixed it:** Switched status code to `HTTP 302 Found` (temporary redirect) and added `Cache-Control: no-cache`.
* **Takeaway / lesson learned:** Use HTTP 301 for permanent domain migrations; use HTTP 302/307 when you want server-side click tracking on redirects.
