## The problem I ran into & how I solved it
* **What I was trying to do:** Deduplicate a list of IP addresses while preserving their original arrival order from network logs.
* **The error:** Converting the list directly via `list(set(raw_ips))` scrambled the chronological ordering because Python sets do not guarantee insertion order preservation across operations.
* **What actually caused it:** Hash sets are unordered collections optimized for lookup, not sequence preservation.
* **How I fixed it:** Used a secondary `seen = set()` alongside a clean result list, checking `if ip not in seen: seen.add(ip); result.append(ip)`. Alternatively in Python 3.7+, `list(dict.fromkeys(raw_ips))` achieves $O(N)$ order-preserving deduplication.
* **Takeaway / lesson learned:** In infrastructure telemetry and audit logs, order preservation is vital for root-cause analysis and chronological incident replay.
