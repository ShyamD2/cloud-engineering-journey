## The problem I ran into & how I solved it
* **What I was trying to do:** Allow user to power on laptop and immediately tap the start button on mobile Telegram without manually running scripts on the laptop.
* **The error:** When laptop booted, Telegram gateway was not running; clicks from phone were queued until manual startup. Running under silent background launchers caused `AttributeError: 'NoneType' object has no attribute 'write'` due to unbuffered `None` streams.
* **What actually caused it:** Headless Windows execution (`pythonw` / `wscript` silent mode) sets `sys.stdout` to `None`, which broke the standard logging stream handler.
* **How I fixed it:** Added safe stream fallback in `logger.py` and stdout redirection to `services/gateway/gateway.log`, created dual Startup folder + Registry Run keys, and added audio/visual feedback on remote start.
* **Takeaway / lesson learned:** True personal AI assistants must operate on zero-manual-touch infrastructure: hardware boot should immediately ready communication gateways for remote activation.
