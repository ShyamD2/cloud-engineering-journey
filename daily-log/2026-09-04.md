## The problem I ran into & how I solved it
* **What I was trying to do:** Calculating subnets dynamically with cidrsubnet
* **The error:** ``Error: Invalid CIDR address: prefix length 28 is greater than max 24`.`
* **What actually caused it:** I passed `newbits = 8` to a `/26` base CIDR, which pushed the prefix beyond `/32`.
* **How I fixed it:** Adjusted newbits parameter to `4` so it produced clean `/30` test subnets from the smaller range.
* **Takeaway / lesson learned:** `cidrsubnet(base, newbits, netnum)` adds `newbits` to the existing prefix length. For a `/16`, `newbits=8` creates `/24` subnets.
